**MethylMapR** Package
By: Chris Morrissey and Arun Sethuraman

**MethylMapR** is an R pipeline for creating functional methylomes from PacBio single molecule real time sequencing data.

MethylMapR expects the PacBio output from kineticstools, specifically the motifs.gff and modifications.csv files.
All other datatypes -- coding sequence, transcriptional data, and transcription factor binding data can be of numerous output types. See the table below for details on the required file/datatype and its purpose.

**Installation**

library(devtools)

install_github("therealtotodile/methylMapR")

library(methylMapR)

or

Download as tarball from Github repo and install it locally from the tarball

**Summary of key functions implemented in methylMapR** 


| Function                     | Required File/Data                        | Purpose                                         |
|------------------------------|------------------------------------------|-------------------------------------------------|
| dfIPD                        | Pac Bio modifications.csv, kineticstools output | Load IPD ratio data                             |
| dfMotif                      | Pac Bio motifs.gff, kineticstools output  | Load motif location data                        |
| dfCDS                        | Annotated genes, .tsv                     | Load CDS location data                          |
| dfTranscription              | Transcriptome, .csv                        | Load transcription abundance data              |
| dfTFBS                       | ChipSeq data, .gff/.csv                    | Load TF binding sites and peak metrics         |
| joinmotifIPD                 | dfIPD, dfMotif                             | Create final methylation dataset               |
| joinmotifGene                | joinmotifIPD output, dfCDS                 | Join methylation and CDS data                  |
| joinmotifgeneTranscription   | joinmotifGene output, dfTranscription      | Join methylation and transcription data        |
| joinmotifgeneFactor          | joinmotifGene output, dfTFBS               | Join methylation and transcription factor data |
| methylinteractionType        | joinmotifgeneFactor output                 | Estimates the TF/motif interaction type        |

**Usage**

```{r}
#To install package:
library(devtools)
install_github("therealtotodile/methylMapR")
library(methylMapR)

#Set directory, change this path!
setwd("C:/Users/cmorrissey/OneDrive - Illumina, Inc/Documents/methylMapR")

#Run Pipeline

#Load motifs.gff
load("~/methylMapR/tests/testthat/data/Motif.rda")

#Load modifications.csv
load("~/methylMapR/tests/testthat/data/IPD.rda")

#Load annotated genes, .tsv
load("~/methylMapR/tests/testthat/data/CDS.rda")

#Load transcription data, .csv
load("~/methylMapR/tests/testthat/data/Transcription.rda")

#Load transcription factor binding site data
load("~/methylMapR/tests/testthat/data/TFBS.rda")

#Combine methylation and motif data
print(class(Motif$strand))
motifIPD <- methylMapR::joinmotifIPD(IPD,Motif)

#Combine methylation motif with gene annotation data
motifGene <- methylMapR::joinmotifGene(CDS,motifIPD)

#Combine methylation motif + gene sets with transcription data
motifgeneTranscription <- methylMapR::joinmotifgeneTranscription(motifGene,Transcription)

#Combine methylation motif + gene sets with TFBS data
motifgeneFactor <- methylMapR::joinmotifgeneFactor(motifGene, TFBS, 10)

#Predict methylation/transcription interaction types
methylinteractionType <- methylMapR::methylinteractionType(motifgeneFactor, 10, 100)
```
